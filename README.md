# 🍽️ Zomato Restaurant EDA
## Dataset
The dataset used in this project contains information about Indian restaurants, including ratings, cuisines, pricing, votes, photos, and city-wise details.

Dataset Source:
[https://drive.google.com/file/d/1rEkayuF89_5yodom5v1MQdpX2x2BKs3U/view]

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the Zomato Indian Restaurants dataset. The objective is to uncover insights about restaurant ratings, cuisines, pricing, customer engagement, and city-wise trends across India.

## 🎯 Objectives
- Analyze restaurant distribution across cities
- Identify top-rated cities and cuisines
- Study customer voting and photo upload behavior
- Explore pricing trends and restaurant ratings
- Understand factors influencing customer satisfaction

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Insights
- Bangalore has the highest number of restaurants in the dataset.
- Gurgaon recorded the highest average restaurant rating.
- North Indian cuisine is the most popular cuisine type.
- Hyderabad received the highest average customer votes.
- Mumbai and New Delhi lead in photo uploads.
- Most restaurants fall within the budget-friendly price segment.
- Higher-priced restaurants generally receive slightly better ratings.

## 📈 Analysis Performed
- Data Cleaning & Preprocessing
- Missing Value Handling
- Univariate Analysis
- Bivariate Analysis
- Correlation Analysis
- City-wise Restaurant Analysis
- Cuisine Analysis
- Rating & Cost Analysis
- Data Visualization

## 📂 Project Files

## 🚀 Conclusion
The Indian restaurant market is dominated by budget-friendly and casual dining outlets. While premium restaurants tend to achieve better ratings, customer satisfaction is influenced by multiple factors such as cuisine quality, service experience, restaurant features, and customer engagement.
